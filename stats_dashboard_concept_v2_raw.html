Design Notes · Raw Readout view

Companion to the dashboard concept — sixth segmented tab labelled 06 RAW. When selected, the whole content area becomes a single dense readout table. Everything that's visualized elsewhere is also exposed here as a row, plus a few quality / meta indicators that don't fit naturally on the dashboard.

  1. One table, five sections. Overview, Hydraulic Head, Gradient Field, Triangle Analysis, Quality & Meta. Each section header carries the same § number used on the dashboard panels (§ 02) so the two views are clearly indexed against one another.
  2. Eight columns: №, METRIC, VALUE, UNIT, Δ BASELINE, STAT (LED), TREND (mini sparkline), NOTE. Numeric columns are right-aligned with tabular nums; the NOTE column uses the same italic Bitter serif as the field-note blocks on the dashboard.
  3. Status LED column. One coloured pip per row — info (cyan), ok (sage), warn (amber), err (rust), muted (grey). Lets you scan the table in 2 seconds and find every row with a non-ok status. The composite data_quality_score (§ 05) summarises all of them in a single 0–100 number.
  4. Sparkline trend column for any metric where history exists. Empty for one-shot metrics (range, IQR, etc). Colors match the status — rust for downward trend, sage for upward.
  5. Section-color left bars. Each section-header row gets a 3-px coloured inner shadow on the left — cyan for Overview/Head, sage for Gradient, amber for Triangles, rust for Quality. Visually anchors the section without taking a whole column.
  6. Hover state for data rows lights an amber bar on the left + tints the row background — same affordance as the section bar, so hover feels like "this is now the active row." Clicking a row would link through to the corresponding plot or the data-table view (e.g. clicking top_freq_in_rejections → Triangle Inspector filtered to point 114.1578).
  7. Control bar above the table exposes:
    • Section chips — toggle which sections are visible (LED-tagged like the status pips so they share a visual language).
    • Search box with mono input, regex-capable, / shortcut to focus and esc to clear. Search compares against the metric key (not the note prose) to keep results predictable.
    • Density toggle — Compact / Dense / Verbose, controlling row padding. Verbose mode would also unfold any abbreviated values to full precision.
  8. Δ Baseline column shows delta against the pinned baseline (set via the topbar's PIN BASELINE button). Up arrow = gain, down arrow = warn (or vice-versa depending on whether the metric being up is good). Flat ±0.00 rendered in a ghosted grey so it disappears against changes.
  9. Table footer summarises: row count · section count · warning/error counts · baseline-pin timestamp. Actions live on the right — copy visible (TSV for paste into spreadsheets), full CSV export, PDF report.
  10. Pure-data, scannable. No charts, no widgets, no animation beyond the topbar pulse and contour drift — this view is for the user who wants to scan every number at once, copy/paste rows into a notebook, or grep for an outlier ID.

Why this complements the dashboard

  • The dashboard answers "is this dataset healthy and what's the headline story?" — visual first, contextual prose, charts.
  • The raw view answers "give me every number" — keyboard-driven, no chrome, exportable in one click. Engineering audiences want both modes available at all times.
  • Both views read from the same derived-cache layer, so switching tabs is instant (no re-derive).

Implementation notes

  • In Qt5 this is best built as a QTreeView (not a plain QTableView) so section headers can group child rows and be collapsible. The model is a lightweight QStandardItemModel populated from the existing derived-cache dict; rows render via a custom delegate that paints the LED pip and sparkline.
  • Sparklines render as QPainter polylines on the cell rect — no matplotlib needed for inline 80×14 px strokes. History buffer is whatever the existing perf-log / dataset session keeps.
  • The status pip uses the same colour mapping as the dashboard LED dots — single source of truth in Colors.
  • Section chips + search + density toggle replace the current scattered placeholders in the existing Statistics panel — same set of controls handles both views.
