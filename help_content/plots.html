Plots & Visualisation

The Plot page is the main workspace. A compact toolbar along the top lets you switch plot types, toggle overlays, and open drawers. The customisation sidebar on the left provides plot-specific controls.

Plot Types

2D Hydraulic Head

A scatter plot of all measurement points coloured by hydraulic head value. Options include:

  • Colormap — choose from a range of colour ramps (e.g. viridis, coolwarm, plasma).
  • Point size — adjust marker radius.
  • Labels — display point IDs and/or head values. Modes: All, Smart (avoids overlap), Off, or Pinned (only selected).
  • Contour overlay — add filled contours and/or contour lines with adjustable level count, interpolation method, and spatial extent.

3D Surface

A three-dimensional surface interpolated from the data points. Controls:

  • Elevation / Azimuth — rotate the view angle with sliders.
  • Surface alpha — set transparency of the interpolated surface.
  • Wireframe — toggle a wireframe overlay on the surface mesh.
  • Colormap — same selection as 2D.

Gradient Vectors

Displays computed gradient vectors as arrows originating from triangle centroids. Options:

  • Scale — control arrow length scaling.
  • Alpha — arrow transparency.
  • Colormap — colour arrows by gradient magnitude.
  • Downsampling — skip vectors in dense areas for clarity.
  • Show points — overlay the measurement points.

Gradient Histogram

A frequency histogram of all valid gradient values. Controls:

  • Bin count — number of histogram bins.
  • Bar / Edge colour — customise appearance.
  • Statistics overlays — toggle vertical lines for mean, median, and confidence interval.

Rose Diagram

A polar plot showing the directional distribution of gradient vectors. Options:

  • Mode — Count or Frequency.
  • Bins — number of angular sectors.
  • Mean / Weighted mean lines — toggle directional statistics.
  • Confidence interval — show angular spread.

Customisation Sidebar

Click the ≡ (hamburger) button in the plot toolbar to toggle the 220 px customisation sidebar. Its contents change automatically to match the active plot type.

Plot Styles

A style selector in the toolbar lets you switch the overall aesthetic:

  • Default — standard appearance.
  • Minimal — reduced chrome, thinner lines.
  • Scientific — axis ticks and grid suitable for technical documents.
  • Publication — high-contrast, serif fonts, ready for journals.

Toolbar Toggles

Quick pill-shaped toggles in the toolbar control overlays:

  • Grid — show/hide background grid lines.
  • Legend — show/hide the colour bar or legend.
  • Compass — show/hide a compass rose on the plot.
  • Dark Canvas — switch the plot background between light and dark.

Canvas Interaction

  • Scroll to zoom in/out.
  • Click & drag to pan.
  • Hover to see coordinate tooltips.
  • Click a point to select it (highlights connected triangles).
  • Ctrl+Click to multi-select points.

Bottom Drawers

Two collapsible drawers sit below the plot canvas:

  • Table drawer (≡ button) — shows the attribute data table or the triangle table. Switch between them with the Data / Triangles toggle. Columns are sortable and filterable. Selecting a row highlights the corresponding geometry on the plot.
  • Stats drawer (↗ button) — a compact panel with real-time gradient statistics and dataset summary.
Tip: Right-click a row in the triangle table to open the Triangle Inspector dialog for detailed geometry and rejection analysis.
