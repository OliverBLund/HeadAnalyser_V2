Map View

The Map page (green icon in the sidebar) displays your measurement points on an interactive geographic map powered by Folium and OpenStreetMap tiles.

Coordinate Conversion

HeadAnalyser assumes that X/Y coordinates in your data are in UTM Zone 32N (EUREF89 / ETRS89). They are automatically converted to WGS84 (latitude/longitude) for map display. If your data uses a different coordinate system, the points may appear in the wrong location on the map.

Warning: If your points appear far from their expected location, verify that your input coordinates are in UTM32N. Other projections are not currently supported for the map view.

Map Features

  • Markers — each data point is shown as a clickable marker on the map.
  • Popups — clicking a marker opens a popup showing the Point ID and Hydraulic Head value.
  • Pan & Zoom — use the mouse or on-screen controls to navigate.
  • Tile layer — OpenStreetMap is the default base map.

Using the Map

The map is primarily a spatial reference tool. It lets you confirm that your points are in the correct geographic location and helps you understand the spatial distribution of your measurement network.

Tip: You can include a static map image in your PDF report. Enable the Include location map option in the report dialog. Note that this feature requires Selenium and ChromeDriver.
