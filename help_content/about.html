About HeadAnalyser V2

Version: 2.0 Beta

Developed by: Oliver Brincks Lund

Institution: DTU Sustain (Danmarks Tekniske Universitet)

Overview

HeadAnalyser is a specialised desktop application for the analysis of hydraulic head data and the computation of groundwater gradients. It was developed at DTU to support researchers and practitioners working with borehole and well data.

The application builds on Delaunay triangulation to compute per-triangle hydraulic gradients, provides configurable quality filters, and offers a range of interactive visualisations — from 2D scatter plots and 3D surfaces to gradient vector maps and directional rose diagrams.

Key Features

  • Multi-format data import (CSV, Excel, JSON) with auto-detection.
  • Five interactive plot types with customisable styles.
  • Configurable triangle quality filters and rejection analysis.
  • Triangle Inspector for detailed per-point investigation.
  • Interactive geographic map (Folium / OpenStreetMap).
  • PDF report generation with plots, tables, and statistics.
  • Multi-dataset support with independent tabs.
  • Light/dark theme support throughout the application.

  • Python 3 with PyQt5 for the desktop framework.
  • Matplotlib for plotting and figure export.
  • SciPy for Delaunay triangulation and interpolation.
  • NumPy / Pandas for data processing.
  • Folium for geographic map rendering.
  • ReportLab for PDF report generation.
