Data Filtration & Calculation Settings

HeadAnalyser provides two layers of data control: data-level filters that remove individual points, and calculation settings that control which triangles are accepted or rejected during gradient analysis.

Data Filters (Properties Panel)

The right-hand properties panel contains interactive range sliders that filter your dataset in real time.

Depth Range

A dual-handle slider that limits points to a specific depth interval. Only points within the selected range are included in the triangulation. The current min–max values are displayed next to the slider.

Hydraulic Head Range

Same dual-handle slider for hydraulic head values. Useful for isolating a specific head interval or removing obvious outliers.

Note: Adjusting a range filter immediately triggers a recalculation of triangles and gradients. The plot and statistics update automatically.

Excluded Points

You can manually exclude individual points from the analysis:

  • Select a point on the plot, then use the Properties panel to exclude it.
  • Excluded points appear in the panel list and can be re-included individually or cleared in bulk.
  • Excluded points can optionally remain visible on the plot with a distinct marker style (e.g. × symbol, reduced opacity).

Calculation Settings

Open the Calculation Settings dialog from the toolbar to configure the triangle rejection rules. These settings control which triangles are flagged as unreliable and removed from the gradient analysis.

ParameterDescriptionDefault
Head uncertainty (L) The assumed measurement uncertainty in hydraulic head values. Used to compute gradient uncertainty per triangle. 0.01
Confidence level Statistical confidence level for the uncertainty test. A triangle is rejected if its gradient uncertainty exceeds the threshold derived from this level. 0.66 (66%)
Base:Height low ratio Minimum allowed ratio of shortest side to longest side. Triangles more elongated than this are rejected for poor geometry. 0.2
Base:Height high ratio Maximum allowed ratio (inverse of the low ratio check). 8.0
Max base or height (L) Upper limit on the longest side of a triangle. Very large triangles spanning distant points are rejected. 1 × 109
Stacked point epsilon Minimum distance between points. Points closer than this are treated as co-located (stacked), and their triangles are rejected. 1 × 10-10

Scope

  • Per-dataset (default) — settings apply only to the active dataset tab.
  • Apply globally — check this box to apply the settings to all open datasets and save them as the new default.

A Reset to Defaults button restores the factory values.

Tip: Start with the default settings and review the rejection breakdown on the Statistics page. If too many triangles are rejected, try loosening the base:height ratio or increasing the uncertainty value.
