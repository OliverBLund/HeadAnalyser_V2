User Interface Overview

HeadAnalyser V2 uses a three-column layout: a coloured navigation sidebar on the left, the main workspace in the centre, and a collapsible properties panel on the right.

Navigation Sidebar

The narrow sidebar on the far left provides access to the three main pages. Each page has a distinct icon colour so you always know where you are:

  • Plot (blue) — the primary visualisation workspace with interactive matplotlib plots.
  • Map (green) — a geographic map view of your data points.
  • Statistics (amber) — a dashboard with summary cards, rejection analysis, and triangle tables.

Header / Toolbar

The toolbar runs across the top of the window and contains grouped action buttons:

File Operations

  • Open File (Ctrl+O) — load a CSV, Excel, or JSON file.
  • Save (Ctrl+S) — save the current session.
  • Export Plot (Ctrl+E) — export the active plot as PNG or PDF.
  • Generate PDF Report (Ctrl+R) — create a multi-page report with selected plots, tables, and statistics.

Analysis Operations

  • Calculation Settings — open the dialog to configure triangle constraint parameters (uncertainty, confidence level, base-to-height ratios, etc.).
  • Attribute Table (Ctrl+T) — toggle the data table drawer at the bottom of the plot page.

Help & System

  • Help — open this documentation dialog.
  • Reset Application — clear all loaded data and return to the welcome screen.

Properties Panel (Right Side)

The properties panel (280 px wide) provides contextual controls for the active dataset:

  • Data Filters — dual-handle range sliders for Depth and Hydraulic Head. Adjusting a slider filters points in real time.
  • Excluded Points — a list of manually excluded point IDs. Points can be removed individually or cleared in bulk.
  • Dataset Context — at-a-glance info: dataset name, point count, triangle counts (total / valid / rejected), and average gradient.

Status Bar

Along the bottom edge you will find:

  • Ready indicator — a green dot confirming the app is idle.
  • File status — the name of the currently loaded file.
  • Coordinates — live X/Y position of the mouse cursor on the plot.
  • Gradient — the gradient value at the current cursor location (when applicable).
  • Point count — total number of data points.
  • Triangle chips — Total, Valid (green), and Rejected (red) triangle counts.

Multi-Dataset Tabs

Each loaded file opens in its own tab. Tabs appear just below the toolbar and can be closed with the × button. Every tab maintains independent data, filters, plot settings, and triangulation results.

Note: Calculation Settings can optionally be applied globally to all open datasets via the "Apply globally" checkbox.
