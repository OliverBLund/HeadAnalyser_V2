Getting Started with HeadAnalyser

Welcome to HeadAnalyser V2 — a specialised tool for analysing hydraulic head data and computing groundwater gradients using Delaunay triangulation.

Introduction

HeadAnalyser lets you load point-based hydraulic head measurements, visualise them in 2D/3D, compute per-triangle gradients, filter out unreliable triangles, and export publication-ready plots and reports. The entire workflow runs inside a single desktop application.

System Requirements

  • Operating system: Windows 10/11 (64-bit).
  • Python: 3.9 or newer (if running from source).
  • RAM: 4 GB minimum; 8 GB recommended for large datasets.
  • Display: 1280 × 720 minimum; 1920 × 1080 recommended.
  • Optional: Selenium + ChromeDriver for map screenshots in PDF reports.

Data Requirements

Your data file must contain, at minimum:

  • Point ID — a unique identifier for each well or measurement.
  • X coordinate — easting or longitude.
  • Y coordinate — northing or latitude.
  • Hydraulic head — the water-level measurement.

Optional columns such as screen depth, top/bottom elevation, and well depth are supported and will be used for filtering when present. See the File Formats page for the full specification.

Opening the Program

Launch HeadAnalyser_V2.exe (or run python main.py from source). The Welcome Screen appears with quick-action cards:

  • Open File — browse for a CSV, Excel, or JSON file.
  • Load Recent — re-open a previously loaded session.
  • Help — open this documentation.
  • Contact — show author and support info.

Quick-Start Walkthrough

  1. Open a file — click Open File or press Ctrl+O. Select your data file.
  2. Map columns — if auto-detection fails, the Column Mapping dialog lets you assign X, Y, ID, and Head columns manually.
  3. Explore the plot — the 2D Hydraulic Head plot loads automatically. Scroll to zoom, drag to pan, hover for tooltips.
  4. Check statistics — click the Statistics tab in the left sidebar to see gradient summaries, rejection breakdowns, and per-point frequency analysis.
  5. Adjust parameters — open Calculation Settings in the toolbar to tweak uncertainty thresholds and triangle quality filters, then re-run the analysis.
  6. Export — use Export Plot (Ctrl+E) for a single image, or Generate PDF Report for a comprehensive multi-page document.
Tip: You can load multiple datasets simultaneously — each opens in its own tab with independent settings.
