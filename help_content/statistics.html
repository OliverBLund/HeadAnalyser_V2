Statistics & Analysis

The Statistics page (amber icon in the sidebar) provides a comprehensive dashboard for understanding your triangulation results, gradient distribution, and rejection patterns.

Summary Cards

Five cards run across the top of the page:

CardDescription
Total TrianglesThe number of Delaunay triangles generated from the point cloud.
Kept TrianglesTriangles that passed all quality constraints.
Rejected TrianglesTriangles removed by one or more filter rules.
Kept / Rejected RatioA stacked bar visualisation showing the proportion of kept vs. rejected triangles.
Average GradientMean hydraulic gradient (m/m) computed from kept triangles only.

Rejection Breakdown

A horizontal bar chart shows how many triangles were rejected by each rule:

  • Uncertainty threshold exceeded — the computed gradient uncertainty exceeds the allowed confidence-based limit.
  • Triangle quality (base:height ratio) — the triangle is too elongated (below the low ratio or above the high ratio setting).
  • Calculation failure — the gradient could not be computed (e.g. co-linear or stacked points).

Each bar is labelled with an absolute count and a percentage.

Point Frequency Analysis

Bar chart showing how often each measurement point appears in a rejected triangle. A threshold slider lets you filter to only show points that exceed a specified rejection rate, which is useful for identifying problematic wells.

Tip: Points with a high rejection frequency may have erroneous head values or may sit in areas of poor spatial coverage. Consider excluding them via the Properties panel.

Triangle Table

A full table of all triangles (kept and rejected) with the following columns:

  • Point IDs — the three vertices.
  • Gradient — computed hydraulic gradient (m/m).
  • Angle — gradient direction (degrees from north).
  • Status — Kept or Rejected.
  • Rejection reason — which rule caused rejection (if applicable).

Columns are sortable. Filter pills at the top allow quick text-based filtering.

Geometry Plot

A matplotlib visualisation of the triangulation mesh. Hovering or selecting rows in the table highlights the corresponding triangles. A heatmap toggle colours triangles by gradient magnitude.

Triangle Inspector

Select one or more points (or right-click a triangle row) and click Inspect to open the Triangle Inspector dialog. This pop-up provides a focused view of only the triangles associated with your selection:

  • Summary cards (total / kept / rejected / ratio / avg. gradient).
  • Geometry plot with point coordinates.
  • Rejection breakdown and per-point frequency bars.
  • Filterable triangle table.

Export

Click the Export button on the Statistics page to save all rejected triangle data as a CSV file for external analysis.
