Exporting Results

HeadAnalyser V2 provides several ways to get your results out of the application: single-plot images, full PDF reports, and CSV data exports.

Export Plot

Use Export Plot (Ctrl+E) in the toolbar to save the currently visible plot.

  • PNG — raster image, ideal for presentations and quick sharing.
  • PDF — vector format, perfect for publications and large-format printing.

The export uses the current plot size and style settings. For higher resolution, increase the DPI in the Plot Settings dialog before exporting.

Generate PDF Report

Click Generate PDF Report (Ctrl+R) to open the report configuration dialog. You can choose which content to include:

Plots

Checkboxes let you select any combination of the five plot types:

  • 2D Hydraulic Head
  • 3D Surface
  • Gradient Vectors
  • Gradient Histogram
  • Rose Diagram

Statistics & Tables

  • General statistics — dataset overview (point count, coordinate ranges, etc.).
  • Gradient statistics — mean, median, standard deviation of gradients.
  • Valid results table — all kept triangles with gradient values.
  • Rejected results table — rejected triangles with rejection reasons.
  • Rejected points analysis — per-point rejection frequency.

Map (Optional)

If the Include location map checkbox is enabled, a static map image is rendered. This requires Selenium and a compatible ChromeDriver installation.

Note: Report generation can take a minute for large datasets with high DPI settings. A progress dialog shows the current step and allows cancellation.

Export Rejected Triangles

On the Statistics page, the Export button saves all rejected triangle data as a CSV file. This is useful for external analysis or quality-assurance workflows.

Data Table Exports

The attribute data table (toggled with Ctrl+T) supports inline editing. Changes to values trigger an automatic recalculation of triangles and gradients.

Tip: For publication-quality figures, switch to the Publication plot style before exporting — it uses high-contrast colours and serif fonts.
